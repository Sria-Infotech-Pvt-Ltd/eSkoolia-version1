# Library module: security and quality audit

Written at the end of prompt 13 (2026-10-08) against branch `library-r`. Every row names the code that does the job and the test that proves it. Tests live in `backend/apps/library/tests/` unless a path says otherwise. `test_audit.py` was written for this audit and fills the rows that earlier prompts proved only indirectly.

**How it was run:** `python -m pytest apps/library` with `DATABASE_URL_TEST=sqlite:///test_library.sqlite3` and `--nomigrations`: 840 passed, 4 skipped. The 4 skipped tests need PostgreSQL row locks and are listed under row 9. Nothing was run against the shared database, and no browser, worker, Redis or WebSocket was used.

## Defects this audit found and fixed

| Defect | Found by | Fix |
|---|---|---|
| The donations list ran a permission query for every row (38 queries for 35 rows): an N+1 | `test_audit.py::test_every_remaining_list_has_a_query_bound[donations]` | `DonationSerializer` asks once per request and keeps the answer in the shared serializer context (`serializers/acquisitions.py`) |
| `PATCH stock-audits/{id}/` answered 403 instead of 405, because `partial_update` was not in `disabled_actions` (it was never a hole: the action had no code, so it failed closed) | `test_audit.py::test_every_router_action_has_a_permission_code` | `partial_update` added to `StockAuditViewSet.disabled_actions` (`views/stock.py`) |
